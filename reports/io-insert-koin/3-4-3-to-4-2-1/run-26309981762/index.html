How to read this graph
  • The violet box is the bumped dependency.
  • Red boxes are files that directly import a symbol from the bumped library.
  • Amber boxes are files that depend transitively at distance 1 (they import a red file).
  • Orange boxes are files at distance 2+ (further transitive hops).
  • Solid violet lines are real edges: each direct importer is wired to the dependency.
  • Dashed amber/orange lines are propagation arrows between columns — they show direction (red → amber → orange), not a 1-to-1 adjacency between files. The exact per-file edges live in the BFS graph and are listed in the traceability table below.
